# Xinghong Go

兴红出行平台 · Lovable 提示词包

依据《出行平台功能方案 - 中犇科技.pdf》思维导图提炼。建议在 Lovable 中分 4 个项目分别生成四个端：用户小程序（主）、师傅端 App、代理商 PC、平台管理端 PC。

使用方式

1. 新建项目后，先粘贴「总提示词」生成用户端小程序初版。

2. 再用「模块级追加提示词」逐页精修，每次只改一个页面/区域，避免一次改动太多导致 UI 漂移。

3. 师傅端、代理商端、管理端分别复制对应提示词，新建项目生成。

4. 设计语言在总提示词中统一定义，四个端尽量复用同一套色板、圆角、字号与组件风格。

一、总提示词（用户端小程序）

直接粘贴到 Lovable：

请为我生成一款名为「兴红出行」的城市出行服务小程序（移动端优先的 Web 应用），面向普通乘客，提供出租车和代驾两大业务，支持即时/预约下单、寻车、行程跟踪、支付、评价、订单管理、钱包与优惠券、营销活动、客服售后等完整闭环。全中文界面，底部 Tab 导航固定为「首页 / 订单 / 我的」三个 Tab。

## 设计风格

出行服务类产品，干净、专业、可信赖。主色用科技蓝（#2563EB 或相近色）+ 品牌绿做强调色，暖灰背景（#F5F6F8）+ 白色卡片；重要操作按钮大而醒目，全站卡片圆角不超过 8px；标题层级清晰：页面标题 20-24px、区块标题 16-18px、正文 14px、辅助文字 12px；金额统一显示为 ¥ + 两位小数。不要使用大面积暗色或渐变炫光风格。

## 页面与模块

### 1. 首页（发单页）

- 顶部位置信息区：当前城市 + 当前定位详细地址，可手动切换地址；上车点/下车点输入框，支持地址搜索与历史目的地联想；搜索目的地后地图联动定位。

- 业务选择：出租车 / 代驾两个大按钮切换；代驾下可切换「即时代驾 / 预约代驾」，预约时弹出日期与时间点选择器。

- 帮他人呼叫开关：开启后填写朋友姓名与联系电话、本人支付。

- 车型与服务选择区：经济型 / 舒适型 / 商务型横向卡片，展示预估价格、等待时间、承载人数、车型示例图；附加服务展开项：搬运服务、等候费说明。

- 费用预估区：起步价 / 里程费 / 预估总价 / 优惠券抵扣，可展开费用明细。

- 一键呼叫区：大号主按钮「呼叫代驾 / 呼叫出租车」，下方进入紧急联系人入口。

- 地图展示区：全宽地图，显示起点/终点标记与路线预览（先用占位地图组件，后续接高德/腾讯地图）。

### 2. 寻车 / 派单中页

- 顶部状态区：动态提示「正在为您寻找附近车辆」，可取消（司机接单前免费取消；接单后 2 分钟内免费取消；超时扣费说明）。

- 导航信息区：实时路线、预计等待时长、剩余时间、已行驶里程、起点/终点、路况信息。

- 订单信息卡片：车型、车牌号、预估价格、实时里程、实时时长。

- 司机信息卡片：头像、姓名、评分、接单量、认证信息。

- 安全功能区：一键报警、行程分享、紧急联系人。

### 3. 行程进行中页

- 顶部行程进度（接驾中 → 行程中 → 完成）时间线。

- 行程信息：司机实时位置、剩余距离、预计到达时间、实时路线/路况。

- 车辆信息：车型、颜色、车牌号。

- 行程操作区：联系司机（电话/消息）、修改目的地（输入新目的地并重新预估费用）、结束行程前费用预估。

- 费用明细：起步价 / 里程费 / 时长费 / 附加费 / 优惠抵扣 / 实付金额。

### 4. 行程完成页（支付 + 评价）

- 司机信息：头像、姓名、司机编号、评分、服务单数、认证状态。

- 费用明细：起步价 / 里程费 / 时长费 / 优惠抵扣 / 实付金额。

- 支付状态区：已支付 / 未支付状态切换，支付方式（微信支付 / 支付宝 / 余额），支付时间；未支付时提供支付按钮。

- 评价区：1-5 星评分 + 标签选择（驾驶平稳 / 车内整洁 / 服务态度好 / 路线熟悉 / 音乐好听）+ 文字评价 + 匿名开关。

### 5. 订单跟踪页

- 行程状态时间线：已接单 / 已到达 / 行程中 / 已完成。

- 行程信息：起点地址、终点地址、预计到达时间、实际行驶里程。

- 费用明细展开：起步价 / 里程费 / 时长费 / 等候费 / 夜间服务费 / 高速费 / 停车费 / 优惠券 / 实付金额。

- 安全操作：行程分享、紧急求助、一键报警。

### 6. 订单中心 / 历史订单

- 顶部 Tab：全部 / 待接单 / 进行中 / 已完成 / 已取消。

- 筛选条件：时间范围（近一周默认选中、可自定义日期区间）、服务类型、订单状态分组、支付状态（未支付显示自动取消倒计时,退款订单可过滤）。

- 订单卡片：订单编号（可复制）、业务类型、起终点、订单金额、订单状态、下单时间。

- 订单详情：服务品类标识、代驾师傅工号、出发/目的地详情、实际支付金额、完结时间戳、评价晒单（匿名评价开关）。

### 7. 我的（个人中心）

- 个人档案：头像、名字、昵称、ID、实名认证凭证。

- 账户资产：余额与充值（平台可设定充多少送多少）、优惠券包（立减券 / 满减券 / 折扣券：张数、门槛、适用场景与车型限制、折后价保底、三天过期倒计时标红、过期自动清理）。

- 我的钱包：余额明细、折扣券/满减券查看剩余与已用历史、提现（微信/支付宝/银行卡，起提金额、手续费说明、到账时间）。

- 设置中心：安全中心、隐私设置、常见问题、帮助反馈（联系客服 / 意见反馈）、版本信息、关于（用户协议 / 隐私政策）、消息推送开关、账号注销申请。

### 8. 营销活动页

- 首单立减：阶梯式满减规则配置展示。

- 新人专享券：领取次数限制、设备 ID + 手机号双重去重。

- 邀请有礼：分享裂变链接、唯一邀请码、邀请可得佣金。

### 9. 客服与售后

- 客服中心：计费规则解读、帮助文档库、搜索关键词联想、在线沟通、在线工单提交（工单优先级）。

- 退款售后：原路退回倒计时、退款进度查询、退款失败原因诊断、图片/视频举证上传、投诉处理结果、客服介入记录。

## 交互与状态要求

所有列表要有加载态、空态（无订单、无优惠券）和错误态占位；下单、支付成功、取消订单、评价提交都要有 Toast 或结果页反馈；等待时间、距离、费用实时刷新。

## 技术建议

移动端优先响应式布局；优先使用 Radix/Shadcn 风格组件；地图用占位组件实现交互样式；数据用 mock + localStorage 持久化，后续可替换为真实 API。

二、师傅端 App 提示词

生成「兴红出行」司机端工作台应用（移动端优先 Web，模拟安卓/iOS 师傅接单 App），面向出租车司机和代驾司机，核心是出车收车、接听派单、行程导航、收入与提现。全中文，底部 Tab：工作台 / 接单 / 行程 / 我的。

## 设计风格

与用户端同一套设计语言：科技蓝主色 + 白卡片暖灰底，圆角 ≤8px，大字号按钮，适合驾驶场景的强对比色与清晰排版，金额 ¥ 两位小数。

## 页面与模块

### 1. 工作台（顶部状态区）

- 出车 / 收车大切换按钮：出车状态说明（出车中接收派单、收车后停止派单），出车状态切换后全端状态联动。

- 信息区：所在城市、当前位置、详细地址、今日在线时长统计。

- 业务类型选择：出租车 / 代驾；车型选择（经济型 / 舒适型 / 商务型，展示车型示例、承载人数、预估价格、等待时间）。

- 接单设置区：接单范围（5 公里内 / 10 公里内 / 全城）；专车接单偏好（电子围栏外）；出租车接单（单一车型、电子围栏内）。

- 时间/服务设置：现在出发 / 预约时间（日期 + 时间点选择）；服务类型（即时代驾 / 预约代驾）；代驾接单偏好。

- 帮他人呼叫：下单时填写朋友姓名与联系方式，本人支付。

### 2. 听单 / 接单页

- 听单状态区：听单中提示，今日订单数（已完成 / 进行中）、预估总收入、今日收入。

- 接单卡片：系统派单倒计时、自动接单开关、语音播报与震动提醒开关、订单信息（起点/终点/车型/预估价格/乘客联系方式/备注）、联系人信息（乘车人姓名/联系电话/备注）、发单操作按钮「确认呼叫 / 接单」。

### 3. 行程进行中页

- 导航地图：实时路线、路况、剩余时间、已行驶里程。

- 行程信息：起点/终点、行程时长与里程、费用预估。

- 行程操作：联系乘客（电话/消息）、结束行程（确认后触发行程完成）。

### 4. 行程完成页

- 乘客评价结果（评分 + 标签：驾驶平稳 / 服务态度好 / 准时到达 / 车技娴熟）。

- 费用构成：起步价 / 里程费 / 时长费 / 等候费 / 夜间服务费 / 高速费 / 停车费 / 优惠抵扣 / 实付金额。

### 5. 我的

- 今日 / 本周 / 本月收入；今日订单数。

- 收支明细：订单收入、奖励收入、扣款记录。

- 我的钱包：提现金额、提现账户（微信 / 支付宝 / 银行卡）、起提金额、手续费说明、提现规则、到账时间。

- 车辆管理：驾驶证 / 行驶证 / 营运证、证件审核状态（审核中/通过/失败）、年检有效期、车辆型号牌号、车辆外观照片。

- 司机资料：实名认证、车辆认证、驾驶证认证、综合评分、服务评分、服务单数、历史五星好评率、实时评分、接单数据统计（总完单量、进行中订单、日均在线时长）。

- 设置中心：消息推送开关、账号注销。

三、代理商 PC 后台提示词

生成「兴红出行」区域代理商管理后台（PC 端 Web），代理商只能看到自己区域的数据，页面包含：工作台 / 驾驶舱 / 订单 / 财务 / 电子围栏 / 运营配置 / 场外运营。全中文。

## 设计风格

运营后台风格：信息密度高但整齐，左侧深色侧边导航 + 顶部面包屑，浅灰底白卡片，表格带筛选与分页，关键指标用大数字卡片；用蓝 + 绿 + 橙色做分类强调。

## 页面与模块

### 1. 工作台 / 数据驾驶舱

- 今日概况：GMV 总额、完单总量、退款订单冲销、剔除取消订单、同比上周增幅、环比昨日趋势。

- 核心指标：司机数（所在区域司机数量、离线数量）。

- 趋势图表：七日订单折线图、收入构成饼图（电子围栏内）、代驾业务占比、平台抽成占比。

### 2. 订单管理

- 全量订单检索：订单号精准查、司机姓名模糊查、复合筛选器、时间区间筛选、金额区间筛选。

- 订单监管：投诉中订单、异常订单池、取消率过高单。

- 拼车/包车呼叫：输入起点与终点出现拼车价格；包车呼叫属一口价服务。

### 3. 财务对账

- 平台分成比例、代理佣金结算、分账明细、提现审核。

### 4. 电子围栏

- 地图圈选电子围栏范围；调配区域订单费用；分时段/天气/高峰差异化定价（仅出租车业务）。

### 5. 运营配置与场外运营

- 区域定价策略、营销活动投放、当前定位地址维护。

- 场外运营场景：乘车二维码（车内扫码进入下单页，用户扫码选包车/拼车）、支持招手拦车、线下支付给司机记录、司机垫付于平台的财务记录。

## 数据隔离要求

代理商子账号只能访问本区域数据与订单，页面顶部明确显示当前区域。

四、平台管理端 PC 后台提示词

生成「兴红出行」平台总管理后台（PC 端 Web），全局 BI 大屏 + 用户/司机/订单/财务/电子围栏/系统对接等管理能力。全中文。

## 设计风格

与代理商后台一致的管理系统风格，但增加全局 BI 大屏模块（深色数据大屏卡片用于展示类页面），其余页面保持浅色工作台风格。

## 页面与模块

### 1. 全局大屏（BI）

- 大屏展示所有运营数据：订单量、GMV、趋势图；订单播报；警报（超时未接单播报，支持关闭/开启）。

- 呈现接单人数。

### 2. 用户名录

- 注册用户列表：用户标签、最近活跃时间、注册地址展示。

- 风控：恶意投诉记录、黑名单管理、刷单作弊封禁。

### 3. 人员管理

- 专车/出租车司机列表：驾驶证有效期、准驾车型范围。

- 代驾司机列表：健康证有效期。

- 在岗司机列表、服务分排名、司机名录。

### 4. 订单管理

- 全量订单流水查看、订单号/司机姓名检索、时间与金额区间筛选。

- 订单监管：投诉中订单、异常订单池、取消率过高订单。

### 5. 电子围栏

- 可调控所有区域的电子围栏、对电子围栏范围圈选、调配区域内订单费用与差异化定价。

### 6. 财务

- 平台分成比例、代理佣金结算与分账明细、退款订单冲销、提现审核。

### 7. 系统对接

- 地图接口、预测接口、出租车车顶灯对接（屏幕展示逻辑）、订单播报配置。

五、模块级追加提示词（逐页精修）

在生成初版后，复制对应段落追加到对话里单独精修某个模块：

1. 地图组件：把首页和行程页的地图升级为真实地图组件，支持起点/终点标记、路线预览、周边车辆数量展示、点击地图选点；移动端地图占页面高度 40%，操作区浮于地图上方但不遮挡主要按钮。

2. 支付流程：完成支付页支持微信 / 支付宝 / 余额三种支付方式切换，选择后按钮文案变为对应支付渠道；支付成功进入结果态（大对勾 + 实付金额），失败展示重试；余额不足时提示充值并跳转钱包。

3. 优惠券系统：优惠券列表展示面额、门槛、适用场景与车型、有效期倒计时（3 天内标红）；结算时自动选最优券，支持手动换券；展示优惠明细弹窗。

4. 评价体系：星级评分 1-5 星 + 推荐标签流式选择 + 文字评价 + 匿名开关；司机端对称展示乘客评价结果。

5. 订单筛选与历史订单：近一周默认选中、自定义日期区间（最大跨度 3 个月）、服务类型、订单状态分组（已取消/已完成/进行中）、支付状态（未支付自动取消倒计时）；订单编号一键复制。

6. 司机接单卡片：卡片展示倒计时进度环、订单起终点缩略地图、价格、距离、乘客备注；自动接单开关、语音播报、震动提醒设置。

7. BI 数据驾驶舱：工作台顶部大数字指标卡 + 折线图/饼图图表卡片，支持时间范围切换，图表带 tooltip 与图例。

8. 电子围栏地图编辑器：地图上支持矩形/圆形圈选区域，选中后可配置费用倍率与时段定价（早/中/晚/雨雪/高峰期），仅出租车业务启用。 帮我做一个ui效果图
